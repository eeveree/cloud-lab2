云计算与分布式系统实验二

基于 GitHub Pages 的 Web 页面部署

Hello World！你已成功访问本实验的测试页面。

实验目的

了解云端静态网站的发布流程， 掌握从创建代码仓库到通过浏览器访问网页的方法。

实验环境

  • 本地操作系统：Windows 11
  • 代码托管平台：GitHub
  • 网站托管服务：GitHub Pages
  • 页面技术：HTML 和 CSS

实验内容

  1. 创建 GitHub 公开仓库。
  2. 编写并提交 index.html 网页文件。
  3. 配置 GitHub Pages 发布来源。
  4. 通过网站地址验证页面访问。

页面版本：v1.1，已完成网页更新验证。

说明：本页面使用静态网站托管，不涉及数据库和后端程序。
